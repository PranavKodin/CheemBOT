# 🐶 Cheems Discord Bot

**A Discord bot that speaks like Cheems while I learn Python and bot development.**  
Made with 💻 Python + 🧠 trial & error.

---

## 📜 About This Repo

This repo is my personal learning playground where I'm creating a Discord bot that talks like the legendary **Cheems Doge** — mispronounced, relatable, and full of floofy humor 🐾

While building this bot, I’m also learning:
- Python basics
- Discord API via `discord.py`
- Bot event handling and commands
- How to deploy and maintain a bot

---

## 🧠 Learning Goals

As a beginner developer, I’m exploring:

- 🔤 **Python Language Fundamentals**  
  - Variables, loops, functions, conditions, error handling.
  
- 🔧 **Discord Bot Modules & Logic**  
  - `discord.py`: The Python wrapper for the Discord API.
  - Event listeners: `on_message`, `on_ready`, etc.
  - Slash commands and custom prefixes.
  
- 🎛️ **Bot Features in Progress**  
  - Responds like Cheems with "funy talk"
  - Basic commands like `!help`, `!ping`, `!cheemify <text>`
  - Cheemify: A function that mispronounces text in Cheems style 😗
  
---

## 🔌 Requirements

To run this bot, you’ll need:

- Python 3.10+
- `discord.py` (`pip install discord.py`)
- A Discord Bot Token (from [Discord Developer Portal](https://discord.com/developers/applications))

```bash
